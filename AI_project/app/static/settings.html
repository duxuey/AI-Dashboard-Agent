AI-Dashboard-Agent —— 可视化查看 AI agent 的调用路径、日志与上下文。

  • 技术栈：Python · FastAPI · DeepSeek (OpenAI 兼容)
  • 数据来源：本看板自建任务 + Canvas 设计器 AI 助手埋点上报
  • 历史记录落盘于 traces/ 目录，重启后仍可查看
🛠️ 当前配置
💡 修改配置说明

模型、API 地址、监听端口等配置项存储在项目根目录的 .env 文件中。修改后需重启服务生效。

  • DEEPSEEK_MODEL — 使用的模型（如 deepseek-v4-flash）
  • DEEPSEEK_BASE_URL — API 地址
  • DEEPSEEK_API_KEY — API 密钥
  • HOST / PORT — 监听地址与端口
  • SYSTEMS — 接入的系统注册表（key:显示名，逗号分隔）
